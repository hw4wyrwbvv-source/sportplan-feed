# Sportplan-Widget – Einrichtung (iPhone)

1. **Scriptable** aus dem App Store installieren.
2. Scriptable öffnen → **+** → Inhalt von `Sportplan-Widget.js` einfügen → Name „Sportplan“ → fertig.
3. Homescreen lange drücken → **+** → Scriptable → Größe wählen (small/medium/large) → Widget hinzufügen.
4. Widget lange drücken → **Widget bearbeiten**: Script = „Sportplan“, **Parameter**:
   - leer oder `glocke` = heutige Events mit 🔔 (Standard)
   - `top` = nur Top-Events
   - `alle` = umfangreich
   - `woche` = Wochenübersicht
   Für mehrere Ansichten mehrere Widgets mit je anderem Parameter anlegen.
5. Tippen aufs Widget öffnet den Tagesplan. Ist der Feed offline, zeigt das Widget den Cache mit „⚠︎ Stand …“.

Feed: Aktualisierung 7:05, 12:05, 18:05 (Glocken-Änderungen kommen mit dem nächsten Lauf).
