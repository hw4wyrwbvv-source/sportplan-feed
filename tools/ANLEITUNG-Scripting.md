# Sportplan-Widget – Scripting-App (mit echtem ↻-Button)

1. App **Scripting** installieren, neues Script/Projekt „Sportplan“ anlegen.
2. Drei Dateien mit den Inhalten aus `scripting/` anlegen: `feed.ts`, `app_intents.tsx`, `widget.tsx`.
3. Homescreen → Widget hinzufügen → Scripting → Script „Sportplan“ wählen, Größe small/medium/large.
4. Parameter (Widget bearbeiten): leer/`glocke`, `top`, `alle`, `woche`.
5. ↻ tippen: lädt den Feed im Hintergrund neu, ohne eine App zu öffnen.
Hinweis: Glocken-Änderungen erscheinen erst, wenn der Feed neu geschrieben wurde (7:05, 12:05, 18:05).
